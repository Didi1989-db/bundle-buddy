# bundle-buddy 🛍️

Una sola spedizione. Tutti gli articoli che vuoi. Risparmi fino al 70%.

> Idea originale di Didi1989-db - 03/11/2026 - All Rights Reserved

### Il problema
Aggiungi 3 articoli dello stesso venditore al carrello e paghi 3 volte la spedizione. Soldi buttati.

### La soluzione
Bundle Buddy rileva quando più articoli appartengono allo stesso venditore e ti propone di unirli in un unico bundle. Una sola spedizione.

Esempio:
- 3 articoli separati = 14,97€ di spedizione
- Con Bundle Buddy = 4,99€
- Risparmi: 9,98€
